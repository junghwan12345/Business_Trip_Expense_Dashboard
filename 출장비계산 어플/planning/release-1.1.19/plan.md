# 정식 앱 1.1.19 배포 계획

## 목표

지출결의서 증빙 시트 자동 생성과 증빙자료 PPT 메뉴 제거를 Windows 정식 앱 업데이트 `1.1.19`로 배포한다.

## 절차

1. 앱 버전을 `1.1.19`로 올린다.
2. 전체 테스트와 문법 검사를 실행한다.
3. Windows 설치파일을 생성한다.
4. 설치파일의 버전과 주요 포함 파일을 확인한다.
5. 개인키로 `release-manifest.json`을 서명한다.
6. 소스 커밋을 정식 저장소에 올리고 GitHub Release `v1.1.19`에 설치파일과 manifest를 게시한다.
7. 원격 Release 파일과 manifest 내용을 다시 확인한다.

## 릴리스 내용

- 지출결의서 Excel에 날짜·항목별 증빙 시트를 자동 생성한다.
- 거리·유가·통행료는 같은 날짜의 현장지원 증빙으로 묶는다.
- 조활비·소모품비·기타 증빙은 각각 분리한다.
- 지출결의서 작성 정보를 이용해 증빙 제목을 만든다.
- 중복된 증빙자료 PPT 제작 메뉴를 화면에서 제거한다.
