# 지출결의서 증빙 시트 자동 생성 결정 기록

- 증빙 시트는 PPT와 같은 분류 체계를 사용하되, 한 날짜를 무조건 하나로 합치지 않는다.
- 거리·유가·통행료는 같은 날짜의 현장지원 증빙 블록 하나로 묶는다.
- 조활비·소모품비·기타는 같은 날짜라도 서로 다른 독립 블록으로 만든다.
- 블록 제목은 Excel에 작성되는 행의 날짜, 방문지 또는 항목, 금액을 우선 사용한다. 연결되는 행이 없으면 날짜와 증빙 종류만 표시하고 결과에 확인필요 건수로 알린다.
- 원본 지출결의서 양식은 수정하지 않는다. 새로 저장되는 복사본에만 `증빙` 시트를 만들거나 다시 구성한다.
- 설치 앱의 서버 저장소와 브라우저 폴더 핸들 두 경로를 모두 유지한다. 브라우저에서 수집한 이미지는 서버 임시 파일로 만든 뒤 Excel에 삽입하고 생성 후 정리한다.
- Windows PowerShell 5.1에서 UTF-8 BOM 없는 스크립트의 한글 상수가 깨질 수 있어 `증빙` 시트명과 고정 안내 문구는 기존 정산월 문자열과 동일하게 Base64 UTF-8 상수로 보관한다.
- 실제 Excel 16.0 통합 검증에서 `증빙` 시트 4개 블록과 이미지 6장 삽입을 확인했다.
- 앱 서버의 업로드 이미지 경로까지 포함한 통합 검증에서 일반출장 1행, 현장지원 1행, 조활비 1행, 증빙 2개 블록, 이미지 4장이 오류 없이 생성됐다.
- Excel COM 객체가 해제된 뒤에도 자동화 프로세스가 남는 환경을 확인해, 생성한 Excel 창의 PID만 기록하고 저장·종료 후 해당 자동화 프로세스만 정리한다. 사용자가 기존에 열어 둔 Excel 프로세스는 유지되는 것을 검증했다.
