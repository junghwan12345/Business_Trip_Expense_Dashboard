# 지출결의서 증빙 시트 자동 생성 계획

## 목표

생성되는 지출결의서 복사본에 `증빙` 시트를 추가하고 자동캡처 이미지를 PPT와 같은 분류 기준으로 배치한다.

## 증빙 블록 규칙

- 거리·유가·통행료는 같은 날짜의 현장지원 블록 하나로 묶는다.
- 조활비·소모품비·기타는 날짜와 항목별 독립 블록으로 만든다.
- 제목은 지출결의서에 작성되는 날짜, 방문지 또는 항목, 금액을 우선 사용한다.
- 연결되는 지출내역이 없으면 날짜와 증빙 종류만 표시하고 확인필요로 집계한다.

## 검증

- 순수 분류·제목 로직 단위 테스트.
- 기존 전체 Node 테스트.
- Microsoft Excel COM을 이용한 실제 통합 문서 생성과 `증빙` 시트·그림 개수 확인.
