# 증빙자료 PPT 메뉴 제거 계획

## 목표

지출결의서 Excel에 증빙 시트가 자동 생성되므로 중복된 `증빙자료 PPT 제작` 메뉴를 사용자 화면에서 제거한다.

## 범위

- 왼쪽 사이드바의 PPT 메뉴를 제거한다.
- 우측 상단 간편 메뉴의 PPT 진입 버튼을 제거한다.
- PPT 화면, 생성 코드, 서버 API, 저장 설정은 추후 복구를 위해 유지한다.

## 검증

- 화면에 `data-page-target="ppt"` 진입점이 남아 있지 않은지 확인한다.
- `data-page-panel="ppt"`와 PPT 생성 버튼이 유지되는지 확인한다.
- 전체 테스트를 실행한다.
