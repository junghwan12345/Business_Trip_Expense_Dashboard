# Personal Dashboard

로컬 브라우저에서 사용하는 개인 대시보드입니다. 오늘의 할 일, 습관, 빠른 메모, 관심 종목, 주식 리서치 노트를 한 화면에서 관리합니다.

## 실행

PowerShell에서 이 폴더로 이동한 뒤 아래 명령을 실행합니다.

```powershell
.\start-dashboard.ps1
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 저장 방식

개인 데이터는 현재 브라우저의 IndexedDB에 저장됩니다. 설정 화면의 `Reset sample data` 버튼으로 샘플 데이터를 다시 불러올 수 있습니다.

## 주식 데이터

관심 종목의 가격 정보는 무료 API를 우선 사용합니다. 네트워크, 호출 제한, API 응답 문제로 실패하면 화면에 `데이터 갱신 실패` 상태가 표시되고 저장된 캐시/기본 상태가 유지됩니다.
