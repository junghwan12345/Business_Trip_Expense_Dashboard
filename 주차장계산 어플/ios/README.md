# iPhone 버전

이 폴더에는 SwiftUI 기반 iOS 앱 초안이 들어 있습니다.

## 열기

1. macOS에서 Xcode를 엽니다.
2. `ios/ParkingFloorNotifier.xcodeproj`를 엽니다.
3. Signing & Capabilities에서 개인 Apple Team을 선택합니다.
4. 실제 iPhone에서 실행합니다. 기압 센서는 시뮬레이터에서 측정되지 않을 수 있습니다.

## 현재 포함된 기능

- 첫 실행 설정: 우리집 위치, 주차장 지상/지하 층수, 현재 주차 위치
- 기압 센서 기반 층 추정
- 기준층 설정, 추적 시작, 현재 층 기록
- 수동 층 기록
- 최근 주차 기록과 기록 수정
- 집 반경, 층당 기압차 보정
- 주차 기록 시 로컬 알림

## iOS 제약

iOS 일반 앱은 안드로이드처럼 페어링된 차량 블루투스 연결/해제 상태를 자유롭게 읽기 어렵습니다. 그래서 첫 iPhone 버전은 기압 추정과 수동 기록을 중심으로 구성했습니다. 이후에는 위치 기반 진입 감지, 위젯, 단축어, CarPlay/External Accessory 가능성을 별도 검토하는 흐름이 좋습니다.
