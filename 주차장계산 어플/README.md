# 주차층알리미 (Parking Floor Notifier)

차로 지상 1층에서 지하 주차장으로 내려가며 주차하는 환경에서,
기압 센서와 차량 블루투스 신호를 이용해 주차한 층을 자동 기록하는 Android 앱입니다.

## 현재 구현 상태

- [x] 실시간 기압 측정 및 층 추정
- [x] 층당 기압차 보정
- [x] Foreground Service 기반 백그라운드 추적
- [x] 차량 블루투스 연결/해제 기반 주차 판단 보조
- [x] 우리집 위치와 반경 설정
- [x] 우리집 근처 진입 시 자동 감지 시작
- [x] 최근 주차 기록 저장 및 층 수정
- [x] 마지막 주차 위치 위젯
- [x] 빠른 층 선택 위젯
- [ ] 실제 주차장에서 장시간 테스트 및 감지 기준 튜닝
- [ ] Play Store 배포용 release 설정

## Android Studio에서 열기

1. Android Studio를 설치합니다.
2. Android Studio에서 **Open**을 누르고 이 폴더를 선택합니다.
3. Gradle 동기화가 끝날 때까지 기다립니다.
4. 휴대폰을 USB로 연결하고 개발자 옵션에서 **USB 디버깅**을 켭니다.
5. 상단 Run 버튼으로 휴대폰에 설치해 테스트합니다.

> 현재 폴더에는 Gradle Wrapper 실행 파일(`gradlew`, `gradlew.bat`)과 `gradle-wrapper.jar`가 없습니다.
> Android Studio에서 여는 방식이 가장 안정적입니다. 나중에 Android Studio 또는 Gradle이 준비되면 Wrapper를 다시 생성해두는 것이 좋습니다.

## APK 만들기

- Android Studio 메뉴: **Build → Build Bundle(s)/APK(s) → Build APK(s)**
- 생성 위치: `app/build/outputs/apk/debug/app-debug.apk`
- 테스트용 APK는 휴대폰에서 "출처를 알 수 없는 앱 설치"를 허용해야 설치할 수 있습니다.

## 테스트 체크리스트

1. 앱 첫 실행 후 우리집 위치, 차량 블루투스, 주차장 층수를 설정합니다.
2. 위치 권한은 가능하면 "항상 허용"으로 설정합니다.
3. 배터리 최적화는 앱이 백그라운드에서 죽지 않도록 제한 없음에 가깝게 설정합니다.
4. 차량 블루투스 연결 상태가 앱 설정 화면에 정상 표시되는지 확인합니다.
5. 실제 주차장에서 내려가며 감지 중 카드와 추정 층이 바뀌는지 확인합니다.
6. 주차 완료 후 최근 기록과 홈 화면 위젯이 갱신되는지 확인합니다.

## 요구 사항

- Android 8.0(API 26) 이상
- 기압 센서(barometer)가 있는 기기 권장
- 차량 블루투스 등록 권장
- 지도 타일 다운로드를 위한 인터넷 연결

## 정리 메모

- `app/build`, `.gradle`, `.idea`는 다시 생성 가능한 산출물/캐시입니다.
- `_apk`는 테스트용 APK를 따로 모아둔 폴더입니다.
- `_backups`는 작업 전 백업 ZIP을 둔 폴더입니다.
